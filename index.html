Blueprint

Independent consulting, 2026. Field-service operations for a grocery-construction contractor.

The contractor’s quotes, field work and books lived in spreadsheets, email and QuickBooks, with no single view from lead to ledger. I mapped how the work actually moved, standardized it, then designed and built the platform to run it.

  1. Discover

    Mapped the contractor’s ad-hoc field processes: how flagged vendor emails, permits and site alerts became work, and how quotes, bills and job costs were tracked.

  2. Define

    Standardized them into workflows, scope and quote documents, and job-cost KPIs, so the build had a spec to meet.

  3. Build

    Designed and built nine modules on SvelteKit, TypeScript and MongoDB, shipped to Azure Container Apps with Entra ID sign-in. Microsoft Graph pulls flagged email, and an OpenAI model turns each message into a job card for a PM to review.

  4. Prove

    Backed it with 560+ automated tests, Playwright end-to-end runs and a WCAG contrast check in CI, so accessibility can’t quietly regress.

  5. Measure

    Put the KPIs on screen: a dashboard for pipeline, win rate and cash on hand, and a job cockpit with margin by store.

  • Dashboard: pipeline and win rate

  • Books: double-entry accounting

  • Quotes: estimates and branded PDFs

  • Prospects: warehouse leads from public data

  • Forecast: Monte Carlo revenue in WebAssembly

  • Job cockpit: margin by store

On iPhone

A SwiftUI companion with the board, dashboard, quotes, prospects and search, offline edits, drag and drop, and a fastlane-to-TestFlight release pipeline.

Lattice

A control plane for local AI models.

Routes each chat to a local model on Ollama or LM Studio and falls back to the cloud when the rig is down. Replies stream over server-sent events, tagged with the backend, tokens per second, time to first token and VRAM. Scheduled agents run saved prompts on a timer.

SvelteKit, TypeScript, OpenAI SDK, Ollama, Tailscale

Lattice on GitHub

Cadence

Meeting notes that never leave the machine.

whisper.cpp transcribes the recording, then a local LLM writes the summary and pulls out action items for each person, with speaker segments and search.

SvelteKit, whisper.cpp, Ollama, SQLite

Timbre

A self-hosted music player with a local model.

The model tags albums by genre and mood and answers plain-English requests, but it can only return tracks that are in the library, and everything falls back to plain rules when no model is running. Loudness leveling runs in hand-written WebAssembly.

SvelteKit, SQLite, Ollama, WebAssembly, Snapcast
